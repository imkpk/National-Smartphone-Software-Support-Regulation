# Contribution Examples

## Good research PR

1. Branch from `main`.  
2. `py -3 scripts/new_research_note.py --domain statutes --slug example-note`  
3. Fill FACT/LAW with real citations only.  
4. Run research-gate checklist.  
5. Open PR using `.github/PULL_REQUEST_TEMPLATE.md`.  

## Rejected patterns

- Uncited “the Supreme Court held…”  
- Litigation drafts before Phase 9  
- Pre-judging forum without `research/forum/` memo
