# Prompts Library

Agent prompt stubs for supervised multi-agent execution.  
**Runtime:** Manual until `MASTER_PROMPT.md` is activated for a research phase.

## Layout

| Path | Purpose |
|------|---------|
| `agents/` | One stub per core agent role |
| `sessions/` | Optional per-run session prompts (create when used) |

## Rules for all prompts

1. Incorporate `VALIDATION.md` by reference.  
2. Forbid fabricated citations.  
3. Require FACT/LAW/ANALYSIS/NORM/OPEN labels.  
4. Forum selection remains open until `research/forum/` is complete.  
5. Do not draft litigation before Phase 9 approval.
