# Citation Policy

**Authority:** Complements `VALIDATION.md`  
**Last updated:** 2026-07-30

---

## 1. Purpose

Ensure every claim in this repository is **traceable, reviewable, and court-defensible**.

## 2. Minimum citation elements

| Material | Required elements |
|----------|-------------------|
| Constitution | Article number; amendment note if material |
| Statute | Short title, year, section/rule |
| Subordinate legislation | Parent Act + rules name + year + rule/schedule |
| Judgment | Case name; court; citation (SCC/AIR/SCR/INSC/neutral); year; holding gist; pin-cite status |
| Policy | Issuing body; title; date; official URL or Gazette ID; access date |
| Web capture | URL; access date (ISO); optional archive link |
| Statistics | Publisher; report title; year; page/table if available |
| OEM policy | Brand; page title; URL; access date; model/series scope |

## 3. Inline labelling

Near each substantive claim use:

- **[FACT]** — source-derived  
- **[LAW]** — legal proposition with citation  
- **[ANALYSIS]** — reasoning  
- **[NORM]** — recommendation  
- **[OPEN]** — unverified / unknown  
- **[SECONDARY]** — secondary source pending primary  

## 4. Preferred primary sources

- India Code / legislative.gov.in / eGazette  
- Supreme Court / High Court official portals or authorised reporters  
- EUR-Lex; European Commission product pages  
- Official OEM support domains  
- ITU/UNITAR Global E-waste Monitor; CPCB/MoEFCC portals  
- CERT-In official site  

## 5. Forbidden

- Invented citations  
- “As held in *X*” without reporter citation for VERIFIED status  
- Wikipedia as sole authority for law  
- Anonymous forum posts as FACT  

## 6. Audit trail

Each research memo must end with a **Sources** section.  
Litigation drafts must map assertions to research file paths or annexure IDs in `evidence/` or `validation/`.
