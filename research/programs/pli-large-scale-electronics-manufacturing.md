# Programme Note — PLI (Large Scale Electronics Manufacturing)

## Repository Relevance

**Why this entity belongs in the repository:**  
Official MeitY **Production Linked Incentive** scheme for large-scale electronics manufacturing including mobile phones — primary industrial programme shaping smartphone production ecosystem in India.

**Tags:** Electronics · Digital Governance · Repository Cross Reference

## Programme Name

Production Linked Incentive (PLI) Scheme for Large Scale Electronics Manufacturing

## Authority

Ministry of Electronics and Information Technology (MeitY)

## Launch Date / Status [FACT]

| Field | Value |
|-------|--------|
| Approval / launch framing | Union Cabinet / MeitY scheme materials (2020 era launch as publicised by PIB/MeitY) |
| Status | Ongoing industrial incentive scheme (confirm current guidelines on MeitY) |
| Official portals | https://www.meity.gov.in/ · PIB scheme releases |
| Access date | **2026-07-31** |

## Objectives [PROGRAMME / FACT]

Incentivise domestic manufacturing of eligible electronics products (including mobile phones as scheme category in official PLI materials) to build scale and competitiveness.

## Programme Scope [FACT]

Manufacturing incentives based on incremental production/sales criteria as set out in scheme guidelines (annex current guidelines PDF for operational pins).

## Key Activities [FACT]

Applicant companies meet investment/production thresholds; incentives disbursed per notified guidelines; mobile manufacturing is a core eligible segment in public scheme descriptions.
