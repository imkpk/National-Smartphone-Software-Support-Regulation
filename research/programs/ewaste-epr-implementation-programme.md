# Programme Note — E-Waste EPR Implementation

## Repository Relevance

**Why this entity belongs in the repository:**  
Official **e-waste Extended Producer Responsibility** implementation under E-Waste Rules — environmental end-of-life programme for electronics including mobile phones; distinct from multi-year OS support product floors.

**Tags:** Environmental · Circular Economy · Electronics · Electronic Waste · Repository Cross Reference

## Programme Name

E-Waste Extended Producer Responsibility (EPR) implementation framework

## Authority

Ministry of Environment, Forest and Climate Change (MoEFCC) — rules; Central Pollution Control Board (CPCB) — implementation/portals/guidelines

## Launch Date / Status [FACT]

| Field | Value |
|-------|--------|
| Legal base | E-Waste (Management) Rules, 2022 (and predecessors historically) |
| Status | Ongoing EPR registration, targets, portal compliance |
| Official URL | https://cpcb.nic.in/ · MoEFCC Gazette/rules materials |
| Access date | **2026-07-31** |

## Objectives [PROGRAMME / LAW / FACT]

Environmentally sound management of e-waste; producer responsibility for collection/recycling as notified in Rules.

## Programme Scope [FACT]

Producers of notified EEE (including mobile phones per Rules schedules — confirm current text); EPR portals and CPCB guidance.

## Key Activities [FACT]

Producer registration, collection targets, recycling through authorised recyclers, reporting on CPCB systems (as published).
