# Supreme Court Source Report — Phase 3 Workstream 1

**Date:** 2026-07-30  
**Agent:** Source Verification  

## Accepted source types

| Type | Use |
|------|-----|
| SCC / AIR / SCR citations as published in standard reporters | Primary case identity |
| Known Constitution Bench / multi-judge identifiers | Bench strength (confirm on reporter) |
| Repository constitution/statute notes | Cross-link only |

## Status of verification

| Level | Meaning |
|-------|---------|
| **Citation identity** | Case name + reporter citation recorded as commonly used in Indian legal practice |
| **Pin-cite / paragraph** | **PROVISIONAL** for all briefs — not line-verified on SCC Online in this automated pass |
| **Ratio nuance** | Summaries are research digests, not substitutes for full judgments |

## Rejected

- Blog case summaries as sole authority  
- Invented citations  
- Cases included only because they mention “technology” without material link  

## Residual risk

Full-text verification on SCC Online / official reports is **required** before court annexure. Fertilizer Corporation parallel citations should be double-checked on the reporter.

## Conclusion

Sources are **acceptable for Phase 3 research digests** with universal PROVISIONAL pin-cite status.
