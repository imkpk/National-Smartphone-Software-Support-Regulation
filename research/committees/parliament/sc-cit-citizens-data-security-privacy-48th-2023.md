# Parliamentary Report Note — Citizens’ Data Security and Privacy

## 1. Report title [FACT]

**Forty-Eighth Report** — Standing Committee on Communications and Information Technology (2022–23) on **Citizens’ Data Security and Privacy**, relating to the **Ministry of Electronics and Information Technology**.

## 2. Committee / Commission [FACT]

Department-related Parliamentary Standing Committee on **Communications and Information Technology** (Seventeenth Lok Sabha).

## 3. Publication year [FACT]

Report of the **2022–23** Committee year (official PDF hosted on sansad.in as Seventeenth Lok Sabha Communications and IT series report **48**). Access date: **2026-07-30**.

## 4. Scope [FACT]

Examination of citizens’ **data security and privacy** under MeitY’s portfolio, including the IT Act framework and (as the report discusses) reasonable security practices under the **Information Technology (Reasonable Security Practices and Procedures and Sensitive Personal Data or Information) Rules, 2011**, and interaction with evolving personal data protection legislation.

Official PDF: https://sansad.in/getFile/lsscommittee/Communications%20and%20Information%20Technology/17_Communications_and_Information_Technology_48.pdf?source=loksabhadocs  
Access date: **2026-07-30**. [T1]

## 5. Key findings [FACT]

From official report materials (as publicly available):

- Notes existence of IT Act provisions and SPDI Rules 2011 as the then-operative reasonable-security framework for sensitive personal data.  
- Examines adequacy of the legal framework for citizens’ data security and privacy in the digital economy.  
- Discusses the need for stronger personal data protection law (context of the then-developing data protection legislation).  

**These findings concern data protection / security practices of data controllers/processors — not multi-year smartphone OS support duties for OEMs.**

## 6. Relevant recommendations [FACT]

Recommendations address strengthening citizens’ data security and privacy governance under MeitY’s domain (see full Observations/Recommendations in official PDF).

**Not identified:** recommendation of a **mandatory minimum multi-year smartphone OS/security support period** for manufacturers.

## 7. Relevance to smartphone software support [ANALYSIS]

| Interface | Note |
|-----------|------|
| Device as data endpoint | Privacy/security of citizens depends partly on device security posture |
| IT Act / SPDI culture | “Reasonable security practices” language is about organisational data handling, not product longevity standards |
| Later law | Digital Personal Data Protection Act, 2023 is separate enacted law (not this report) |
| Gap | No OEM multi-year software-support mandate |

## 8. Limitations

- Report predates full operationalisation of DPDP regime; do not cite as current data-protection statute.  
- Paragraph-level quotes require annexed PDF.  
- Secondary explainers (blogs/news) rejected as authority for what the Committee “required.”
