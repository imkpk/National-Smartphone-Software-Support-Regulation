# Consultation Note — BIS Draft Standards Public Comments

## Repository Relevance

**Why this entity belongs in the repository:**  
BIS operates the formal **public comment** process for draft Indian Standards — the main standards-layer consultation pathway where a future multi-year software-support standard *could* appear. Documents the process, not a specific OS-year draft IS.

**Tags:** Technical Standards · Policy Development · Electronics · Repository Cross Reference

## 1. Title

BIS draft standards open for public comments (process / portal orientation)

## 2. Authority

Bureau of Indian Standards (BIS)

## 3. Publication / consultation period [FACT]

| Field | Value |
|-------|--------|
| Process | Ongoing; each draft has its own comment window |
| Portal | https://standards.bis.gov.in/website/wc-drafts (Draft Standards Open for Comments) |
| Manual | Standards formulation manuals on bis.gov.in describe public comment on drafts |
| Access date | **2026-07-31** |

## 4. Status [FACT]

**Standing consultation mechanism.** Individual drafts are time-limited. Draft IS texts are **not binding** until finalised and, if applicable, made compulsory via QCO.

## 5. Official URL

| Source | Locator |
|--------|---------|
| WC Drafts | https://standards.bis.gov.in/website/wc-drafts |
| BIS home | https://www.bis.gov.in/ |

## 6. Purpose & scope [FACT]

Invite stakeholder and public comments on draft Indian Standards before finalisation.

## 7. Issues discussed [FACT]

Depends on each draft’s subject. This note does **not** assert a specific open draft on multi-year OS support without listing a named draft from the portal at access date.
