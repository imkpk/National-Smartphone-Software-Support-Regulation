## 3. Findings [FACT / ANALYSIS]

### Coverage [FACT]

Repository contains **initial** consumer-law interface notes (Phase 2) distinguishing:

- individual commission remedies vs systemic PIL framing;  
- e-commerce disclosure interfaces;  
- unfair-contract / support-opacity themes;  
- an OPEN issues list.

### What the repository establishes [ANALYSIS grounded in FACT]

| Finding | Support |
|---------|---------|
| CPA framework provides consumer rights, UTP, product liability, CCPA class tools | Statute notes + CCPA regulator note |
| No repository claim that CPA *expressly* fixes multi-year OS support floors | Aligns with statutory negative finding |
| Several **application questions** remain OPEN (material information, defect theory, unfair terms evidence) | `open-issues-list.md` |
| E-commerce rules address disclosure/warranty information duties at platform/seller level | Statute + e-commerce interface note |

## 5. Limitations

- Consumer-law folder is **initial notes**, not a full commission-case digest.  
- No NCDRC / SCDRC case corpus on OS support in repository.  
- Unfair-contract analysis requires real OEM terms (manufacturer research not done — Phase 5 pending).

**High** for documentation that OPEN issues are explicitly tracked.
