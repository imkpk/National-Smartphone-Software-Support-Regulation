# Research Gate Checklist

Use before merging any file under `research/` to `main`.

## Identity

- [ ] Correct domain folder  
- [ ] YAML front matter present (or equivalent header fields)  
- [ ] `status` tag set  

## Integrity

- [ ] Every **LAW** claim has a citation  
- [ ] Every **FACT** has a source  
- [ ] Judgments include official reporter/neutral citation (or status is not VERIFIED)  
- [ ] Statutes include Act year + section/rule  
- [ ] Policies include issuing body + official source  
- [ ] No fabricated authorities  
- [ ] Comparative notes include non-binding-in-India banner where applicable  

## Structure

- [ ] FACT / LAW / ANALYSIS / NORM / OPEN separated  
- [ ] Sources section complete  
- [ ] Open questions listed  
- [ ] Access dates for URLs  

## Outcome

- [ ] PASS  
- [ ] FAIL — return to author with defects
