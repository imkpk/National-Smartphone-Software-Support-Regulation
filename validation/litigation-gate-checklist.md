# Litigation Gate Checklist

**Hard gate:** Phase 9 only. Do not use to authorise early drafting.

## Preconditions

- [ ] Phases 2–8 input pack identified  
- [ ] `research/forum/` analysis complete (forum not pre-judged in Phase 1)  
- [ ] Project Manager Phase 9 approval recorded in CHANGELOG  
- [ ] Citation Validation pass on all cited research  

## Pleading integrity

- [ ] Every assertion maps to research path or annexure ID  
- [ ] No claim of unenacted Indian “minimum years” statute as existing law  
- [ ] Comparative law used as persuasive only  
- [ ] Economic figures labelled estimates where not measured  
- [ ] Client grievances/invoices annexed or marked TO BE ANNEXED  
- [ ] `DRAFT — NOT FOR FILING` banner present until counsel certification  

## Process

- [ ] QA editorial pass  
- [ ] Human counsel review scheduled / completed  
- [ ] Export only after certification  

**Result:** BLOCKED / READY FOR COUNSEL / CERTIFIED
