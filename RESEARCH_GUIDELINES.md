# Research Guidelines

**Last updated:** 2026-07-30

## 1. Workflow

1. Claim a task in `TASKS.md`  
2. Open or create memo under correct `research/` domain  
3. Gather **primary** sources first  
4. Write with FACT/LAW/ANALYSIS/NORM/OPEN labels  
5. Complete Sources section  
6. Run self-check against `VALIDATION.md`  
7. Update TASKS + CHANGELOG + `logs/` note  

## 2. Memo structure (mandatory)

```markdown
# Title
**Domain:**  
**Status:** PROVISIONAL | VERIFIED | ...  
**Last updated:** YYYY-MM-DD  
**Agent:**  

## Scope
## Verified facts
## Law
## Analysis
## Strategic recommendations (NORM)
## Uncertainties / OPEN
## Sources
## Audit trail
```

## 3. Negative findings

If a search finds **no** instrument, record:

- Databases/portals searched  
- Date of search  
- Search terms  
- Conclusion as **negative finding** (not “therefore illegal”)  

## 4. Parallel work

Domain agents may work in parallel; **Citation Validation** must pass before litigation promotion.

## 5. Client evidence

User-supplied grievance numbers and invoices are **FACT** only when primary documents are present. Until annexed, cite as “client-asserted reference pending annexure.”

*End*
